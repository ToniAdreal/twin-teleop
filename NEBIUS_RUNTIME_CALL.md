# Nebius Token Factory runtime call — evidence

This file records a real runtime call made by TwinTeleop's evaluation
pipeline to an NVIDIA open model served on Nebius Token Factory, as
required for the Nebius x NVIDIA Global AI Hackathon (Physical AI track:
"All submissions must run on either Nebius Token Factory or Nebius AI
Cloud and use at least one NVIDIA open source model").

No credentials appear in this file or anywhere in this repo. The call
was made on 2026-10-28 (Beijing) through the connected Token Factory
credential, using the OpenAI-compatible request shape implemented in
`src/model_assist.py` (endpoint `https://api.tokenfactory.nebius.com/v1`,
path `/chat/completions`).

## Call record

- Date (Beijing): 2026-10-28, during the hackathon submission period
- Endpoint host: `api.tokenfactory.nebius.com`
- Model (NVIDIA open model): `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B`
- HTTP status: 200, `finish_reason: stop`
- Usage: 205 prompt tokens, 509 completion tokens, 714 total

## Input (deterministic harness output, generated by this repo)

A 12-frame, 3-joint recorded trajectory was evaluated by
`src/evaluate.py` (default limits: max torque 10 N*m, max joint
velocity 5 rad/s, max gap 100 ms). Result: **FAIL** — only
`velocity_within_limit` failed (peak joint velocity 5.000000000000004
rad/s vs the 5.0 limit; peak torque 0.5 N*m, max gap 20000 us, timestamps
monotonic). The full prompt is reproducible with
`build_assessment_prompt()` in `src/model_assist.py`.

## Model response (verbatim excerpt)

> velocity_within_limit: The trajectory failed because the peak joint
> velocity exceeded the allowed limit. Next action: Reduce the peak
> joint velocity to stay within the limit.

The model narrated the deterministic verdict without overturning it —
exactly the role `src/model_assist.py` assigns it. The verdict itself
still comes from the harness, not the model.

## Reproducing

1. Run the hermetic tests: `python3 -m pytest tests/ -q` (the
   `test_model_assist.py` cases use a local stub server, no key needed).
2. For a live call, set `TWINTELEOP_MODEL_BASE_URL`,
   `TWINTELEOP_MODEL_NAME` and `TWINTELEOP_MODEL_API_KEY` (your own
   Token Factory key) and call `assess_trajectory()` on any
   `EvalReport.to_dict()`.
